# WO-2026-09-30-001: alias foundation rollback

**Rollback of the alias foundation (manual procedure):** AWS fleet-ops holds a diagnostic copy of device telemetry; Ubidots is the system of record. To roll back, redeploy the pre-foundation template. CloudFormation removes the `prod` alias and its two invoke permissions and recreates the per-route permissions itself; do not delete or recreate any of them by hand first. Expect a brief gap (under one minute; ~55 seconds measured in testing) in AWS-side ingestion on affected routes while API Gateway converges. No data is lost from the devices or from Ubidots, only a temporary gap in this diagnostic copy. The published version is retained after rollback; re-applying the foundation later without a function change may fail ("A version for this Lambda function exists"), so check that first. This is an intentional, operator-performed procedure for a rare, deliberate action, not an automated or zero-downtime path.
